# Raw MovieLens data

Run `python -m src.data.prepare` from the repository root to download the official MovieLens 25M archive and extract it into `data/raw/ml-25m/`. Source files and the archive are ignored by Git and must not be redistributed. See [Section 3 of the roadmap](../../Movie_Recommendation_Agent_Roadmap.md) and the [source terms](https://files.grouplens.org/datasets/movielens/ml-25m-README.html).
